## 🔬 Technical Details

### Merkle Tree Implementation
- **Type**: Sparse binary Merkle tree
- **Hash function**: Blake3 (fast, cryptographic)
- **Storage**: HashMap<(level, position), Hash>
- **Depth**: Configurable (default 20 for 1M capacity)
- **Proof size**: 32 bytes × depth (640 bytes for depth-20)

### Performance Characteristics
- Insert: O(log n) with ~2.4 μs/operation
- Proof generation: O(log n) with ~100 μs
- Verification: O(log n) with ~1.5 μs
- Scales to 1M+ nodes efficiently

### Security Properties
- Merkle root commits to entire node set
- Proofs are unforgeable (computational binding)
- Proof size grows logarithmically with tree size
- Dynamic updates require proof refresh (prevents reuse)
